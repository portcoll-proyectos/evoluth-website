# Documentación

- `libro-de-marca.md`: contenido y tono, color, tipografía, espacio, forma y profundidad, y foco y movimiento del modelo Comercial.
- `componentes/`: la guía de cada componente, la misma del sistema de diseño "Evoluth UI · Comercial".

Las guías muestran ejemplos con `Evoluth.icon()` o `Evoluth.loader()`, que son los de las vistas previas del sistema de diseño. En la aplicación se usan los componentes de React con el mismo nombre: `<Icon />`, `<Loader />`, `<AppShell />` y los demás de `src/index.ts`.
